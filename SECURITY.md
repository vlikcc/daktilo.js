# Security policy

## Supported versions

Security fixes are released for the latest minor version of daktilo-js.

## Reporting a vulnerability

Please **do not open a public issue** for security problems. Report them privately through GitHub: **[Report a vulnerability](https://github.com/vlikcc/daktilo.js/security/advisories/new)**.

Include the affected version, a description of the issue and, if possible, a minimal reproduction. You can expect a first response within a week. Once a fix is released, the advisory is published with credit to the reporter unless you prefer otherwise.

daktilo-js runs in the browser and rewrites the DOM of the elements you give it; issues such as HTML injection through options or typed content are in scope.
