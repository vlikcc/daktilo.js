# Test fonts

Latin subsets of the typewriter fonts, used by the visual regression tests so screenshots do not depend on network access or on the fonts installed on the machine.

- **Courier Prime** by Alan Dague-Greene for Quote-Unquote Apps — SIL Open Font License 1.1
- **Special Elite** by Astigmatic — Apache License 2.0

Downloaded from Google Fonts. They are not part of the published package.
